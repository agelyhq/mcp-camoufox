MCP Tool Test Pages

Each page is designed to exercise one or more Camoufox MCP tools.

  • Click — click, double-click
  • Fill — fill text input, textarea, contenteditable, select
  • Evaluate — evaluate JS expressions
  • Press Key — press_key (arrows, Enter, combos)
  • Scroll — scroll (long page, sections)
  • Upload — upload_file
  • Wait For — wait_for (delayed elements)
  • Dialog — handle_dialog (alert, confirm, prompt)
  • Screenshot — take_screenshot (colorful, scrollable)
  • Snapshot — take_snapshot (varied ARIA roles)
  • Network — list_network_requests, get_network_request (AJAX)
  • Infinite Scroll — scroll, wait_for, list_network_requests (AJAX pagination)
